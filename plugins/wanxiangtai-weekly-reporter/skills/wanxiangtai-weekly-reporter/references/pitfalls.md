# 已验证避坑

只在对应阶段读取。

## 页面和素材

- “全部展开”后按钮可能变成“全部收起”；不要继续搜索旧文案，也不要退化为整页正文。
- 素材媒体节点存在懒加载。结构化记录有 ID 但 URL 为空时，滚动对应区段后补读；落盘前逐条断言 URL 非空。
- 同一素材 ID 可能在不同创意行重复出现且指标不同。以页面行作为记录单位，不按 ID 去重。
- 计划汇总与当前可见素材明细可能因归因口径或已删除素材不相等，禁止用明细求和改写计划总计。
- 浏览器剪贴板与 Windows 系统剪贴板可能隔离，不要用剪贴板当结构化数据桥接。

## 飞书表格

- 素材从 G 列开始，容量为 `备注列序号 - 7`，不是 `-5`。
- 插列位置必须在当前物理列范围内。在末列后追加时，以当前末列作为插入锚点。
- `range-copy formats` 会复制合并状态和数据验证，复制后不要再次合并同一区域。
- 复制范围不能切穿跨列合并标题；标题单独写入。
- 空白范围可能仍返回空值行对象；逐值检查，不以 rows 数组是否存在判断。
- PowerShell 单操作数组必须显式保留 JSON 数组外壳。
- 公式中的双引号使用 PowerShell 单引号格式字符串生成，写后读取 formula 字段验证。

## 安全和续跑

- 每个计划原始 JSON 落盘后才处理下一个计划。
- 相同浏览器连接错误最多恢复一次；重复发生就保存状态并停止，避免无效消耗。
- `target block non-empty`、重复周期、计划映射冲突、素材数量不符、URL 缺失、dry-run 失败或回读不符均为停止条件。
- 不通过删除、清空或覆盖历史来恢复。只修复当前未完成计划的明确问题。
