# 飞书周报模板规范

每个计划使用一张工作表。周期块高 27 行，块之间留 1 个空白行：起始行依次为 `3, 31, 59, 87...`，通式为 `3 + 28 × n`。

固定列：

- A：图片区或视频区。
- B：方向说明。
- C：数据截图。
- D：结论。
- E：字段名称或投放日期。
- F：计划总计。
- G 起：素材列。
- 最后一个素材列右侧：填写结论/备注。

默认素材容量为 24 列，即 `G:AD`，备注列 `AE`。容量是初始值，不是业务上限。

## 图片区相对行

| 相对块起始行 | 内容 |
| --- | --- |
| +0 | 计划标题和统计周期 |
| +1 | 图片周期及素材投放日期 |
| +2:+3 | 图片封面 |
| +4 | 类型 |
| +5 | 方向多选 |
| +6 | 展现 |
| +7 | CR |
| +8 | CTR |
| +9 | 直接成交金额 |
| +10 | 花费 |
| +11 | 总 ROI |
| +12 | 直接 ROI 公式 |

## 视频区相对行

| 相对块起始行 | 内容 |
| --- | --- |
| +14 | 视频周期及素材投放日期 |
| +15:+16 | 视频封面 |
| +17 | 视频地址 |
| +18 | 类型 |
| +19 | 方向多选 |
| +20 | 展现 |
| +21 | CR |
| +22 | CTR |
| +23 | 直接成交金额 |
| +24 | 花费 |
| +25 | 总 ROI |
| +26 | 直接 ROI 公式 |

方向多选固定为：用户信任、圈人群、正向、反向、功能、情感价值、使用感受、使用结果。最佳素材背景色为 `#FFF2CC`。
