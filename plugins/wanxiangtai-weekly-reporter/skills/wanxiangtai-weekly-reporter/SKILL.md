# 万相台周报助手

让不同品牌经过一次初始化后，只需提供日期范围，就能把万相台“人群推广”计划及全部图片/视频素材追加到自己的飞书周报。

## 模式判断

- 用户首次安装、要求建表或尚无品牌配置：读取 [references/setup.md](references/setup.md)，执行初始化模式。
- 用户给出日期范围、要求抓取或继续周报：读取 [references/weekly-sop.md](references/weekly-sop.md)，执行周报模式。
- 涉及扩列、页面异常、重复素材或恢复：再读取 [references/pitfalls.md](references/pitfalls.md)。

## 共同约束

1. 万相台只使用用户当前已登录的浏览器会话；不得复制 Cookie、密码、访问令牌或账号凭据。
2. 飞书只使用用户自己的 `lark-cli --as user` 授权。配置文件只保存工作簿 token、工作表 ID 和计划 ID，不保存授权令牌。
3. 隐藏工作表一律不读、不写。`计划月数据`默认排除，除非用户明确要求月度模式。
4. 计划与工作表按一次确认后的稳定映射处理，后续以 campaign ID 和 sheet ID 为主键。不要把“省略人群推广四个字”机械改写成固定前缀删除算法。
5. 素材列表没有业务数量上限：页面列出多少行就记录多少行，不因低数据、重复 ID 或模板列不足而丢弃。超过飞书单表物理列限制时创建同计划的素材续表并记录关系。
6. 每个计划是独立事务：页面核对、结构化提取、原始 JSON 落盘、素材准备、飞书写入、回读验证、更新任务清单；完成后才进入下一个计划。
7. 写入必须是追加式。目标周期已存在、目标块非空、映射不唯一或结构异常时立即停止，禁止覆盖、清空历史或猜测修复。
8. 计划总计照抄平台六项指标；直接 ROI 使用公式 `直接成交金额 ÷ 花费`。图片和视频在各自有有效样本时分别选择一个最佳素材并标黄。

## 日期短指令

当本机只有一个有效品牌配置，且用户只说“抓取 9.7-9.13”之类的日期范围时，直接使用该配置运行，无需重复询问品牌、工作簿或默认排除项。开始前用一句话复述日期与追加规则即可。

存在多个品牌配置时才询问品牌；发现未映射的新计划时只要求确认新增映射，不重新确认已有计划。

## 可复用脚本

脚本位于 [scripts](scripts)：

- `profile_manager.py`：创建、列出和验证每个品牌的本地配置。
- `run_manifest.py`：建立周期任务清单，阻止同周期重复运行并记录断点。
- `find_next_block.ps1`：发现下一空白周期块并检测重复周期。
- `create_brand_workbook.ps1`：按统一结构创建飞书周报和品牌计划工作表。
- `prepare_plan_assets.py`、`make_contact_sheet.py`：准备图片、视频帧和方向判断联系表。
- `build_enrichment.ps1`：复用合法方向标签并补充最佳素材。
- `invoke_expand_sheet_capacity.ps1`：在备注列前安全扩展素材列。
- `invoke_initialize_append_block.ps1`、`invoke_write_plan_to_lark.ps1`：初始化并写入新周期块。
- `invoke_verify_plan_block.ps1`：验证新周期及已有历史周期。

不要把工作簿 token、品牌名、计划 ID、日期或本地绝对路径写死进脚本。

## 完成条件

- 所有当前可见且未排除的计划均有明确状态。
- 每个完成计划的周期、六项汇总、素材行数、图片/视频、视频地址、方向、公式和最佳高亮均通过回读。
- 写入前后的历史周期值与结构一致。
- 任务清单状态为 `complete_and_globally_verified`；否则必须明确列出未完成计划和下一动作。
